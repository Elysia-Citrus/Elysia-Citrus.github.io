## 今日目标

今天从最基础的数组开始，理解数组的访问特点，并练习使用双指针减少不必要的重复遍历。

数组在内存中连续存储，因此可以通过下标在常数时间内访问元素。不过，在数组中间插入或删除元素时，通常需要移动后续元素。

## 双指针思路

双指针并不是一种具体的数据结构，而是一种常见的遍历技巧。它通常使用两个下标从不同位置移动，以降低算法的时间复杂度。

常见形式包括：

- 相向双指针：一个指针从左侧出发，另一个从右侧出发。
- 快慢双指针：两个指针从同一方向出发，但移动速度或职责不同。
- 滑动窗口：使用左右边界维护一个连续区间。

## 示例：有序数组中的两数之和

给定一个按升序排列的数组，寻找两个元素，使它们的和等于目标值。

```ts
function twoSum(numbers: number[], target: number): [number, number] | null {
	let left = 0;
	let right = numbers.length - 1;

	while (left < right) {
		const sum = numbers[left] + numbers[right];

		if (sum === target) {
			return [left, right];
		}

		if (sum < target) {
			left++;
		} else {
			right--;
		}
	}

	return null;
}
```

由于数组已经有序，当当前和偏小时移动左指针，偏大时移动右指针。整个过程只需要遍历一次，时间复杂度为 `O(n)`，空间复杂度为 `O(1)`。

## 学习总结

今天重点理解了数组适合随机访问的特点，以及双指针如何利用有序性减少搜索范围。后续练习中需要继续辨别题目是否具备单调性、连续区间或原地修改等适合使用双指针的特征。
